## Datenschutz (Pilot)

Die App läuft vollständig im Browser. Antworten (Nativ-Test, Daily-Pulse, eigene Rollen) werden **ausschließlich lokal** auf dem Gerät gespeichert (localStorage) — es gibt keinen Server, keine Konten, keine Cookies von Drittanbietern, kein Tracking. Der Daten-Export erfolgt manuell als pseudonyme JSON-Datei (zufällige Geräte-ID, keine Namen). Löschen: Website-Daten dieser Seite im Browser löschen. Die angezeigten Personen sind pseudonymisierte bzw. fiktive Demo-Daten.
